# 阅读与编辑界面

- 紧凑顶栏与工具区，中央满宽大画板；初始不打开节点详情。
- 面向非技术初学者：默认文案说“步骤、原文、修改、保存”，以“看区域 → 点步骤检查或修改 → 保存”说明用法。接入参数、文件校验等技术信息留在管理员资料或必要的展开详情；不得因此隐藏人工责任、来源及待确认信息。主按钮保持用户指定的“生成/保存修改skill”。
- v0.8.1 优先合并功能相近的横向泳道，通常只保留2—3个业务大区；简单同一任务使用1个整体区域。准备、补材料、复核与异常分支留在所属业务区，不因执行人、文档标题或参考资料不同而拆区；共用资料和约束就近放入支持的业务区，不单独成为主泳道。目标或独立交付确实不同、合并会更难理解时可保留更多区域，不硬凑数量。
- 每区有白话标题、一句用途和步骤数量，背景颜色辅助识别，不单靠颜色。定稿前检查相邻区能否用一句具体白话说明共同目标，能就合并，但不把不同目标硬塞进“综合处理”。区域顶部提供跳转入口，点击后聚焦该区，再用“看全图”返回；默认仍显示全图。合并不丢步骤、条件、责任、原文或连线，不暗加审批，也不以区域顺序推断先后。旧图兼容的自动分区须注明仅便于阅读，不无依据改写旧图语义。
- 主线从左到右，分支上下分层，回路单独绕行；资料依赖不伪装成顺序步骤。
- 悬停节点或 Tab 聚焦时突出它的一跳连接、上下游与引用节点，并淡化无关内容；用文字徽标区分关系。移出或失焦还原，点击才开编辑气泡；搜索条件与草稿不变。保存页重开不携带临时悬停态。
- 节点气泡就近打开，限制宽高并自动避开视口边缘；内部内容可滚动，原手册证据保持只读。
- 编辑直接进入当前草稿。关闭、点空白、Escape 或切换节点不丢失草稿；可重新点开继续修改。
- 初始及重开默认全图，支持鼠标拖动平移和以鼠标位置为中心的滚轮缩放；另有适合阅读和 100%。气泡内滚动只滚动内容。窄屏以底部面板承载编辑，避免出屏。
- 保留修改差异、候选 Skill 导出、保护来源文件及图待重新解读提示。

## 连线可读性

服务于非技术初学者，默认图就应能追踪起点、终点、条件与返回位置。悬停高亮是辅助，不能代替基础可读性。

- **主线短而顺。** 主流程尽量从左向右，相邻步骤能直接连接时不绕远路。不因有标签就统一绕到顶部；先调整步骤间距和出入口，再安排必要的绕行。
- **条件跟着自己的线。** 条件文字靠近所属线路，留出阅读空间，不压线、步骤、标题或其他文字，也不摆在更靠近另一条线的位置。关键否定、例外及暂停范围不能为简短而省掉；完整说明仍可在步骤详情查看。
- **分支和汇合清楚。** 同一步骤多条出口尽量使用错开的出入口和独立通道。共用一段路径仅用于确实容易辨认的同源分支或同目标汇入，始终保留每条边的箭头与条件；不同去向的线路不能长距离重合到无法区分。
- **回路和跨区线路单独安排。** 返回线优先沿区域外侧或专用空白通道，明确返回位置；跨区连线就近穿越边界，避免贯穿无关区域和正文。不能为“横向统一”把返回关系改成向前执行。
- **交叉不冒充汇合。** 优先减少交叉；仍有交叉时用间隔或跨越效果帮助区分，避免画出没有业务含义的交汇点。不承诺任意复杂图都没有交叉。
- **主次同时可辨。** 主流程、条件、回路与参考资料使用线型、箭头和文字共同区分。资料引用适当弱化，但保留可追踪性，不单靠颜色判断含义。

交付前至少沿一条主线、一个实际存在的条件分支、返回路径和跨区关系逐条追踪；没有该类关系时不造测试分支。检查线不穿步骤或标题、文字不互压、箭头归属清楚、线路没有因重叠而看似连到别处。调整布局和通道不能删边、改条件、改执行方或把资料引用画成必经步骤。几何与自动交互检查不能替代真实浏览器的字体与视觉验收。

## 视觉与可访问性

页首只显示 Skill Lens 名称。画板使用浅色底，深色正文和蓝绿强调；选中、引用、条件与待确认状态同时提供文字说明。保留键盘焦点、悬停预览与窄屏底部编辑面板。
