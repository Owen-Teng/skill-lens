# 阅读与编辑界面

- 紧凑顶栏与工具区，中央满宽大画板；初始不打开节点详情。
- 主线从左到右，分支上下分层，回路单独绕行；资料依赖不伪装成顺序步骤。
- 悬停节点或 Tab 聚焦时突出它的一跳连接、上下游与引用节点，并淡化无关内容；用文字徽标区分关系。移出或失焦还原，点击才开编辑气泡；搜索条件与草稿不变。保存页重开不携带临时悬停态。
- 节点气泡就近打开，限制宽高并自动避开视口边缘；内部内容可滚动，原手册证据保持只读。
- 编辑直接进入当前草稿。关闭、点空白、Escape 或切换节点不丢失草稿；可重新点开继续修改。
- 初始及重开默认全图，支持鼠标拖动平移和以鼠标位置为中心的滚轮缩放；另有适合阅读和 100%。气泡内滚动只滚动内容。窄屏以底部面板承载编辑，避免出屏。
- 保留修改差异、候选 Skill 导出、保护来源文件及图待重新解读提示。

## 视觉与可访问性

页首只显示 Skill Lens 名称。画板使用浅色底，深色正文和蓝绿强调；选中、引用、条件与待确认状态同时提供文字说明。保留键盘焦点、悬停预览与窄屏底部编辑面板。
